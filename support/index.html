What to expect

We prioritise every ticket by urgency — a system that is down is always our highest priority — and keep you updated on progress.

Keep your SM number. Each logged query gets a unique support (SM) reference — quote it on any follow-up so we can pick up exactly where we left off.

Getting the fastest resolution

Best method of contact — the preferred way to reach the helpdesk is by email (QuickEasy Application > Main Menu > Help > Email Helpdesk), so you are never left holding for an operator.

Note: for your security, the helpdesk cannot bypass user settings or install software to access your database directly. For example, to edit a report over TeamViewer we need a user login with report-editing rights; to use FlameRobin we need to work from a computer where it is already installed.

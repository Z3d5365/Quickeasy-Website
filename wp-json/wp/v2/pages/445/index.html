Allow Us To Address Some Concerns About Cloud Hosting<\/h2>\n\t

Server-Based Anti-Virus –<\/strong> Windows Defender runs as a background process on the server to identify and neutralise any potential threats. As the QE application is accessed from a secure desktop icon and no users are opening emails, etc. directly on the server the threat level is reduced.<\/p>\n

QE Backups and Schedules –<\/strong> Backups are performed daily with a copy kept on the cloud server and also copied to a second system.\u00a0 Versions of your backups are kept for 30 days before they are deleted.<\/p>\n

Backup Tests –<\/strong> Manual backup checks are conducted monthly, where the backup is restored, checked and then saved on a different ISP drive.<\/p>\n

Server Hardware Backups –<\/strong> The AWS cloud environment is not limited to a “single server”, but lies on a much larger distributed computing system which has global redundancy. For South African customers it is preferable to use the Cape Town locale to reduce latency to the server. Other locations in Ireland, Singapore and Bahrain are suggested for customers outside the ZA region. In the unlikely event that an AWS location is unavailable or compromised, QE has the ability to rebuild the database in another location within hours.<\/p>\n

On-site Backups –<\/strong> The only instances of on-site backups are for customers who have chosen on-prem servers.<\/p>\n\t\t\t\n\t\t\t\t\t\t\tDisaster Recovery Plan: QuickEasy Database Recovery on AWS EC2\n\t\t\t<\/a>\n\t

BOS Cloud Hosting

With BOS Cloud Hosting, you stay connected to your business, and keep your data safe, even when the lights go off.

Peace of mind

Allow us to address some concerns about cloud hosting

Server-Based Anti-Virus

Windows Defender runs as a background process on the server to identify and neutralise potential threats. As the QE application is accessed from a secure desktop icon and no users open emails etc. directly on the server, the threat level is reduced.

QE Backups and Schedules

Backups are performed daily, with a copy kept on the cloud server and also copied to a second system. Versions of your backups are kept for 30 days before they are deleted.

Backup Tests

Manual backup checks are conducted monthly, where the backup is restored, checked and then saved on a different ISP drive.

Server Hardware Backups

The AWS cloud environment isn't limited to a "single server" — it lies on a much larger distributed computing system with global redundancy. South African customers typically use the Cape Town locale to reduce latency; Ireland, Singapore and Bahrain are suggested for customers outside the ZA region. In the unlikely event an AWS location is unavailable or compromised, QE can rebuild the database in another location within hours.

On-site Backups

The only instances of on-site backups are for customers who have chosen on-prem servers.
